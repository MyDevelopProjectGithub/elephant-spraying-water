# 🐘 Elephant Spraying Water

**An Open-Source SwiftUI Arcade Game**

Help the elephant protect baby elephants! Spray water to smash falling rocks and keep the little elephants safe.

## 🎮 Gameplay

- Control an elephant at the bottom of the screen.
- Spray water to break falling rocks.
- Protect baby elephants from dangerous falling obstacles.
- Enjoy a fun and casual arcade gaming experience.

## 🛠 Tech Stack

- Swift
- SwiftUI
- Xcode
- Native iOS Development

## 🎯 Project Goals

This project aims to demonstrate casual game development with SwiftUI and provide an accessible learning resource for iOS developers.
